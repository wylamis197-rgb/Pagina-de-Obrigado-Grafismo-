## Publicação na Vercel

1. Importe este repositório na Vercel.
2. Selecione o framework **Other**.
3. Deixe o comando de build vazio.
4. Use a raiz do repositório como diretório de saída.
5. Publique.

A página é HTML, CSS e JavaScript nativos; não precisa de instalação de dependências.
